The problem

Nine disciplines, one shared question

Faculty and students across architecture, apparel, graphic, interior, landscape, product, retail, UX, and human factors design were all asking which AI tools are worth learning. The answers lived in scattered lists, vendor pages, and hallway conversations.

The Atlas puts those answers in one place, organized around the design process the College already teaches.

Design decisions

How it is built

  1. Matrix first, network second. Rows answer "what is this and when do I use it." The network answers the one question rows handle badly: what connects to what.
  2. No color coding by discipline. Nine hues cannot stay distinguishable for color-blind readers, so discipline is carried by label and position. Color marks state only.
  3. A stable map. The network layout is seeded, so it looks the same on every visit and placement issues can be reproduced.
  4. Honest sourcing. Uncited statistics are flagged in place instead of reading as verified.
  5. Kept current. A daily scan proposes new tools and pricing changes to a review queue. Nothing publishes without review.
